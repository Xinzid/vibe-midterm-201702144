# ☕ 카페 메뉴 주문 및 확인 웹앱

카페에서 메뉴를 선택해 장바구니에 담고 주문하고, 관리자(매장 직원)는 대시보드에서
주문 현황과 재고를 확인·처리하는 웹앱입니다.

HTML/CSS/JavaScript만 사용했으며, 별도 서버 없이 브라우저 **localStorage**에
모든 데이터(메뉴 재고, 장바구니, 주문 내역)를 저장합니다.

## 주요 기능

- **음료 5종**: 아메리카노, 카페라떼, 바닐라라떼, 카푸치노, 녹차라떼
- **옵션**: 샷 추가(+500원), 시럽 추가(+0원)
- **장바구니**: 담기 · 수량 조절 · 삭제 · 합계 자동 계산
- **주문**: 주문 시 재고 차감, 재고 0 시 **품절(SOLD OUT)** 처리
- **관리자 대시보드**: 주문 현황 · 제조 완료 처리 · 메뉴별 재고 현황 · 재고 보충/초기화
- 고객/관리자 화면은 탭으로 전환

## 사용법

### 고객 (주문)
1. 원하는 메뉴의 옵션(샷/시럽)을 선택합니다.
2. "장바구니 담기"를 누릅니다.
3. 장바구니에서 수량·삭제를 조정하고 합계를 확인합니다.
4. "주문하기"를 누르면 주문이 접수되고 재고가 차감됩니다.
5. 재고가 모두 소진된 메뉴는 "품절"로 표시되어 주문할 수 없습니다.

### 관리자 (대시보드)
1. 상단 "관리자" 탭을 누릅니다.
2. **주문 현황** 탭: 접수된 주문을 확인하고 "제조 완료 처리"를 누릅니다.
3. **재고 현황** 탭: 메뉴별 남은 재고를 확인하고 "+1 보충" 또는 "전체 재고 초기화"를 누릅니다.

## 기술 스택

- localStorage (데이터 영속화)
